This is a recreation of the ZX Max Plus D Issue 1 PCB as designed by DonSuperfo but done in KiCAD 10.

This was only done in order to create an interactive BOM (in the BOM folder) to assist in the assembling of the PCB.

The KiCAD schematics 'should' be correct but nothing should be assumed as correct without checking with the original schematic and PCB layout. Although I have followed the original track and via layout further checking should be done before using these files to order a pcb with.

Use at your own risk.
